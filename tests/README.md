# 投資紀錄開發測試

給下一位維護者。一般使用者直接從主畫面開啟 App 即可。

## v10.7 美股手續費與成交對帳

- 美股與 ETF 預設 IBKR Pro 階梯式第一級，每月不超過 30 萬股。期權預設自動選擇交易場所（SmartRouting）、每月不超過 1 萬口。每一列代表一筆委託，分批成交先合併。保留手動實付、自訂百分比、其他券商與日股年均費率。舊交易的預估沿用儲存值。[IBKR 股票費率](https://www.interactivebrokers.com/en/pricing/commissions-stocks.php) · [IBKR 期權費率](https://www.interactivebrokers.com/en/pricing/commissions-options.php)
- 2026 年 11 至 12 月使用核對過的結算、稽核、轉嫁及賣出規費。期權選交易所時加入該場所的每口監管費。其他日期僅估基本佣金。估計未含依成交場所與提供或取用流動性而異的費用或回饋。更新費率時按適用日期區分並新增邊界測試。[交易所監管費](https://www.interactivebrokers.com/support/faq/content/options-regulatory-fee-orf-1112364993)
- 「交易 → IBKR 成交對帳」接受每行七欄，依序為帳本當地日期、時間、美股代號或完整標準期權代號、動作、數量、成交均價及美元實付手續費。買賣方向與合約須完全相同，成交時間須在十分鐘內。僅提供唯一配對的預覽，支援股票股數和單價顛倒及券商顯示單價的四捨五入。套用前重驗交易和期權口數。實付保留小數精度，裝置保存上次對帳前的紀錄供復原。
- 前端沿用 GAS v13 的整筆交易合併與編輯時間。此次型別欄位為 `feeModel`、`feeVenue`、`feeActual`。測試使用虛構資料。個人的成交單與對帳文字只在有帳本的裝置輸入。

## v10.6 交易手續費

- 舊版依市場使用年均費率，期權以成交權利金為基礎。換匯費用另計。
- 儲存新股票交易後記住該市場的自訂費率。手動填寫的實付金額只套用在當筆，金額為零也有效。
- 年均預估金額取到交易幣別小數兩位，交易帶有選填的 `feeEstimateRate`。手動實付保留輸入精度。讀取舊交易時繼續採用原金額或原費率，GAS 沿用 v13。
- 手機測試使用虛構成交，涵蓋美股買賣、切換日股與台股、其他券商偏好、編輯舊交易、期權乘數與實付金額覆寫。設 `SCREENSHOT_DIR` 可輸出手續費區塊的手機截圖。

## v10.5 期權自動報價

- 沿用 GAS v13 的 `action=quotes`。前端依完整合約代號、到期日、Call／Put 及履約價向 Yahoo 查詢市場成交價。來源為美國期權延遲行情，畫面顯示來源時間。價格影響未平倉估值與損益。
- App 開啟時，盤中每分鐘查詢，到收盤後保留一段時間接收延遲成交。其他時段每小時重查，手動按鈕可立即查詢。到期日以紐約日期判斷。非 100 的乘數或無法精確表示的代號、履約價沿用手動報價。
- 市場報價儲存在原本的合約價格欄位，`qt` 為市場時間（秒），`at` 為同一時間（毫秒）。GAS v13 依 `at` 合併，因此較舊的市場成交不會覆蓋較新的手動報價或成交估值。
- 手機測試從只有模擬期權持倉的帳本開啟 App，核對自動查價、估值及沒有行情時的處理。另測合約比對、調整型乘數、紐約到期日、股票夜盤分流，以及手動輸入和自動更新同時發生的情形。

## v10.4 IBKR 美股與 ETF 期權

- 從「＋ → IBKR 期權」進入。交易沿用原本的交易編號、同步、備份、匯入與刪除復原。正式帳本的初始資料由使用者自行輸入。GAS 沿用 v13。
- 合約用標的代號、到期日、買賣權、履約價和權利金乘數區分。股票及每個合約各自記帳。經調整的合約應使用成交單上的合約代號及乘數。
- 買賣開倉及平倉採 FIFO。手續費為整筆美元金額，依配對口數分攤。賣方市值為負數，權利金淨收付在總覽另列。合約估值優先用使用者手動輸入的現價，否則用最近一筆期權成交價。股票報價及股票今日盈虧各自計算。
- 到期歸零需手動確認。履約、指派及相應股票交割尚未支援。
- 手機測試涵蓋賣出 Call、修改成交、輸入合約報價、部分買回、刪除復原、超額平倉阻擋、Put 的 FIFO 與無價值到期。開啟 `SCREENSHOT_DIR` 也會保存期權表單畫面。GAS 相容性測試會核對合約與手動報價通過試算表合併後的內容。

## v10.3 夜盤與日股

- 夜盤使用 GAS v13。設定頁複製出的程式要與根目錄的 `Code.gs` 一致。請在 Google Apps Script 的原專案儲存並重新部署新版本。
- 美股夜盤每分鐘輪詢 Yahoo 的夜盤價格與成交時間。無資料時保留最後報價。假日及真實夜盤覆蓋須用部署後的服務核對。
- 東證股票以 `7203.T` 等完整代號區隔台股。交易、手續費及成本是日圓，股數採實際股數。總覽依最新取得的美元兌日圓匯率換算，歷史圖留存快照當時的換算值。

## v10.1 交接

- 網頁入口是根目錄的 `index.html`。設定畫面的 `gasCode()` 會把 GAS 主體與 `mergeCore` 組成完整程式。本次沿用 GAS v12。
- 修改前的網頁可以從 [v10.0 的固定版本](https://github.com/GGDADER/portfolio/blob/e54d1c7375dd4d3caa06ec4c3f6e8b8f25313410/index.html) 取回。
- 每日首次有交易時留一份本機快照，依裝置日期保留七份。內容含交易、刪除紀錄、報價及歷史。介面可以匯出整份檔案，也可以單獨預覽並補回交易。當日快照保存後即保留原貌。
- GAS v12 會永久記住已刪除的交易編號。明確復原時前端分配替代編號，並接回指定的買入批次及相同時間的先後順序。一般 JSON 匯入只補入預覽中缺少的交易。
- iPhone 的導覽列、選單、提示及視窗使用容器內定位。交付前要實際點過表單欄位、離開輸入框，再點下方按鈕。

## 執行

在專案根目錄使用 Python 3.13 與 Node.js 20 以上。

```sh
python -m pip install playwright==1.58.0
python -m playwright install chromium webkit
node tests/test_gas_compat.mjs
python -m unittest discover -s tests -v
```

Linux 若缺系統套件，將安裝瀏覽器的指令改為 `python -m playwright install --with-deps chromium webkit`。以環境變數 `BROWSER` 與 `VIEWPORT` 選擇瀏覽器和尺寸。手機使用 WebKit 390×844、Chromium 375×667，桌面使用 Chromium 1280×800。例如在 PowerShell 執行下列指令。

```powershell
$env:BROWSER='webkit'
$env:VIEWPORT='390x844'
python -m unittest discover -s tests -v
```

設定 `SCREENSHOT_DIR` 可保存「備份與復原」畫面的截圖。測試使用獨立的瀏覽器空間及虛構交易；所有網路請求都在測試內攔截。GAS 相容性測試直接執行網頁內附的 GAS，以記憶體模擬試算表。正式行情服務、Google 部署權限、iOS 實體鍵盤觸控仍須在對應環境驗證。
